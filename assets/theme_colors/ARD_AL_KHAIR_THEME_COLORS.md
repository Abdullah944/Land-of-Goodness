# أرض الخير — Theme Colors

This file defines the official visual color palette for **أرض الخير (Ard Al Khair)**.

Use these colors consistently across UI, menus, HUD, buttons, icons, logo, buildings, environment details, decorative assets, and future generated artwork.

The overall feeling should be:

**warm, peaceful, cozy, Kuwaiti/Gulf-inspired, natural, welcoming**

## Main Palette

| Role | Color Name | HEX |
|---|---|---|
| Main Sand | Warm Beige | `#E7C99A` |
| Background | Soft Cream | `#FFF3DC` |
| Primary | Palm Green | `#5E9B62` |
| Secondary | Olive / Sage | `#8EAD72` |
| Highlight | Warm Gold | `#D9A441` |
| Wood | Date Brown | `#7A4F32` |
| Water | Gulf Blue | `#55AFC4` |
| UI Accent | Soft Teal | `#4F9F9A` |
| Warm Accent | Terracotta | `#C96F4A` |
| Dark Text / Outline | Deep Brown | `#3F2D27` |

## Core Visual Combination

The main visual identity should primarily use:

- **Soft Cream**
- **Warm Beige**
- **Palm Green**
- **Date Brown**

Accent colors:

- **Warm Gold**
- **Soft Teal**
- **Gulf Blue**
- **Terracotta**

Avoid using too many accent colors at the same time.

## UI Guidelines

Preferred panel colors:

- Background: `#FFF3DC`
- Secondary panel areas: `#E7C99A`
- Border / outline: `#7A4F32`
- Dark text: `#3F2D27`

Primary buttons should usually use `#5E9B62`.

Use `#D9A441` for selected states, rewards, and special highlights.

Secondary actions can use `#4F9F9A`.

Use `#C96F4A` sparingly for warnings or important attention states.

## Water and Fishing

Primary water color:

`#55AFC4`

Use lighter blue highlights and darker natural blue shadows when needed.

Water should feel colorful and peaceful, not neon.

## Environment

For farms, villages, and Gulf/desert areas, favor:

- `#E7C99A` — sand, plaster, ground
- `#FFF3DC` — light walls and highlights
- `#7A4F32` — wood
- `#5E9B62` — vegetation
- `#8EAD72` — secondary plants

Preferred Kuwaiti/Gulf materials:

- beige plaster
- cream stone
- warm brown wood
- palm greens
- gold lantern details
- teal / blue small accents

Avoid making the whole world yellow or brown. Green plants and blue water should provide contrast.

## Text

Primary dark text:

`#3F2D27`

Avoid pure black where possible.

For text on dark backgrounds, use `#FFF3DC` or another light cream derived from the palette.

## Gold Accent Rule

Gold:

`#D9A441`

Use for rewards, special highlights, selected UI, decorative trim, and important positive moments.

Gold should remain an accent, not the dominant interface color.

## Art Direction

Future assets should follow:

- smooth 2D cartoon style
- warm lighting
- soft shading
- clean outlines
- colorful but not neon
- natural Gulf / Kuwaiti atmosphere
- cream, sand, green, and brown as the foundation

The game should visually feel:

**peaceful + warm + friendly + natural**

## Important Rule for Future Assets

When generating or creating new artwork for أرض الخير:

1. Start with the main palette.
2. Keep the same warm color temperature.
3. Avoid random color schemes that do not match the game.
4. Keep UI colors consistent across all screens.
5. Keep dark outlines closer to `#3F2D27` instead of pure black when possible.
